Calculons la durée d'une image à 72, 90 et 120 hertz, au dixième de milliseconde

* pour 72Hz  durée = (1/72)*1000 = 13,9ms
* pour 90Hz  durée = (1/90)*1000 = 11,1ms
* pour 120Hz  durée = (1/120)*1000 = 8,3ms

En soutrayant les 8ms, il reste respectivement pour 72, 90 et 120 hertz, pour le code :
5,9ms
3,1ms
0,3ms (impossible de travailler dans ce budget car même seulement pour les capteurs il est insuffisant)
